# PORTFOLIO-JAVASCRIPT-JULIAN-RIZZATO

Mini Proyectos JavaScript

Este repositorio contiene varios mini proyectos realizados con HTML, CSS y JavaScript, pensados para practicar lógica, DOM, eventos y programación básica.

Incluye ejercicios en archivos individuales y pequeñas aplicaciones interactivas dentro del navegador.

📌 Contenido del proyecto
1. Calculadora (HTML + JS)

Una calculadora funcional con botones para números y operaciones básicas.
Incluye manejo de errores, reinicio automático de pantalla y evaluación de expresiones.

2. Formulario de registro

Formulario con validaciones:

-Campos obligatorios
-Validación de email
-Mínimo de caracteres en la contraseña
-Muestra mensajes de error y de éxito.

3. Reloj digital

Reloj en tiempo real que cambia de color según la hora del día:

-Mañana
-Tarde
-Atardecer
-Noche

4. Calculadora por prompt

Calculadora en consola usando prompt(), validación de datos y operaciones básicas (+, −, *, /).

5. Adivina el número

Juego en el que el usuario intenta adivinar un número aleatorio entre 1 y 20, con 6 intentos.

6. Tablas de multiplicar

Genera una tabla hasta un límite elegido por el usuario y guarda los resultados en un arreglo, incluyendo un recorrido con for...of.

7. Conversor de temperaturas

Convierte:

-°C → °F
-°F → °C
-°K → °C

Usa funciones clásicas y funciones flecha.

8. Lista de compras

Trabaja con:

-forEach, reduce, filter, find
-Agregar y eliminar productos dinámicamente
-Mostrar total a pagar

9. Agenda de contactos

Pequeña agenda con funciones para:

-Agregar contactos
-Buscar
-Mostrar

Eliminar
Los datos se guardan usando localStorage.

10. Navegación entre páginas

Un index.html que actúa como menú principal para acceder a:

-Calculadora
-Formulario
-Reloj

🛠️ Tecnologías utilizadas

HTML5

CSS3

JavaScript (ES6+)
